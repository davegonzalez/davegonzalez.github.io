# davegonzalez.github.io

Static homepage deployed via GitHub Pages.

## Files

- `index.html`: single-page site markup.
- `styles.css`: merged typography + global + layout/home styles.
- `fonts/`: self-hosted Rubik and Merriweather font files.
- `favicon.png`: site favicon.

## Local Preview

Open `index.html` directly in a browser.
